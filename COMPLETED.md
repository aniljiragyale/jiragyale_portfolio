## 📞 Quick Reference

### Update Email Keys
File: `script.js` (Line 40)
```javascript
emailjs.init("YOUR_PUBLIC_KEY");
emailjs.send('YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', {...})
```

### Change Profile Image
Files: `index.html` and `about.html`
```html
<img src="YOUR_IMAGE_URL" alt="Your Name" class="photo-img">
```

### Customize Colors
File: `styles.css` (Lines 11-27)
```css
--bg:       #050d1a;      /* Background */
--accent:   #63b3ed;      /* Primary color */
--accent2:  #4fd1c5;      /* Secondary color */
```

All HTML files have navigation - update href="" values
